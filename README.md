## About this project:

The project contains an analysis of historical FIFA World Cup match data using MySQL. 

The dataset contains information about World Cup matches (goals, teams, attendance) from the first World Cup in 1930 to the present. 
The SQL skills which were used are:

- SQL data cleaning
- GROUP BY
- CASE WHEN
- CTE
- UNION/UNION ALL
- Window Functions
- RANK() and ROW_NUMBER()


The analysis includes questions such as:

- How many matches were played at each World Cup?
- How many goals did each team score?
- Which team scored the most goals at each World Cup?
- What percentage of all goals was scored by the top-scoring team?
- How did attendance develop across different World Cups?
